klToolbox – Hilfe

Alle Funktionen im Überblick. Die Einstellungen dazu findest du in den Optionen; dort lassen sich alle Module abschalten — die Ticketsystem-Erweiterungen zusätzlich auch einzeln („Ticketsystem-Funktionen einzeln“), falls eine davon Probleme macht.

Erste Einrichtung

  • Konfiguration importieren: Optionen → Sicherung → „Importieren (aktualisieren)“ mit der intern verteilten Konfigurationsdatei (bringt Links, Vorlagen, Branding und die Ticketsystem-URL mit).
  • Ticketsystem freigeben: Nach dem Import erscheint der Button „Zugriff auf … erlauben“ — einmal klicken und die Browser-Abfrage bestätigen. Erst dann sind die Ticket-Module aktiv (offene Ticket-Tabs einmal neu laden).
  • API-Key eintragen: Optionen → KI-Umformulierer → beim gewählten Anbieter den eigenen API-Key hinterlegen.
  • Private Fenster erlauben: In der Erweiterungsverwaltung „Im Inkognito-Modus zulassen“ (Chromium) bzw. „In privaten Fenstern ausführen“ (Firefox) aktivieren — nötig für die Links, die im privaten Fenster öffnen, und den Inkognito-Reset.

KI-Funktionen

Der KI-Anbieter und das Modell werden in den Optionen gewählt — verfügbar sind Claude (Anthropic), ChatGPT (OpenAI), InnoGPT (mit großem Modellkatalog inkl. Preisen je 1 Mio. Tokens) und Azure OpenAI als „Copilot for Business“-Weg (eigene Azure-Ressource des Microsoft-Tenants: Endpoint, Deployment, Key). „Eigenes Modell…“ erlaubt beliebige Modell-IDs. Darunter zeigt die Token-Verbrauchsstatistik die genutzten Tokens der letzten 24 Stunden, 7/30 Tage und des letzten Jahres (nur lokal erfasst).

KI-Anbieter einrichten

Für alle Anbieter gilt: Key in den Optionen eintragen, die Zustimmung zur Datenübertragung anhaken, speichern — der Status-Bereich oben zeigt, ob alles grün ist. Es genügt, einen Anbieter einzurichten.

Claude (Anthropic):

  1. console.anthropic.com → Konto anlegen bzw. anmelden, unter Billing Guthaben/Zahlungsmittel hinterlegen
  2. API Keys → Create Key → Key (sk-ant-…) kopieren — er wird nur einmal angezeigt
  3. In den Optionen bei „Claude" eintragen; Modell-Empfehlung: Haiku (günstig) für Alltagsaufgaben

ChatGPT (OpenAI):

  1. platform.openai.com → anmelden, unter Billing Guthaben aufladen (Prepaid)
  2. API keys → Create new secret key → Key (sk-…) kopieren
  3. In den Optionen bei „ChatGPT (OpenAI)" eintragen

InnoGPT:

  1. Bei app.innogpt.de anmelden (Zugang der Organisation)
  2. Im Bereich Entwickler & API einen API-Key (sk_live_…) erzeugen
  3. In den Optionen bei „InnoGPT" eintragen; Modell aus dem Katalog wählen (nach Kosten sortiert)

Azure OpenAI („Copilot for Business“-Weg): Daten bleiben in der gewählten Azure-Region eures Microsoft-Tenants und werden nicht zum Training verwendet; Abrechnung über den Azure-Vertrag.

  1. portal.azure.com → Ressource erstellen → „Azure OpenAI" → Abonnement, Ressourcengruppe, Region (z. B. Germany West Central oder Sweden Central) und einen Ressourcennamen wählen → erstellen
  2. In der Ressource (bzw. im Azure AI Foundry-Portal) unter Deployments ein Modell bereitstellen — z. B. gpt-4o-mini. Der dabei vergebene Deployment-Name ist frei wählbar und wird später exakt so in den Optionen eingetragen
  3. In der Ressource unter Keys and Endpoint: den Endpoint (https://<ressourcenname>.openai.azure.com) und KEY 1 kopieren
  4. In den Optionen bei „Azure OpenAI": Endpoint, Deployment-Name, Key eintragen; API-Version im Zweifel auf 2024-06-01 lassen → Anbieter „Azure OpenAI (Business)" auswählen, Zustimmung anhaken, speichern
  5. Kurztest: Text markieren → Rechtsklick → „KI: Text bearbeiten" → Umformulieren. Bei Fehler 404 stimmt meist der Deployment-Name nicht, bei 401 der Key
Direktzugriff auf M365 Copilot per API-Key gibt es nicht — Azure OpenAI ist der von Microsoft vorgesehene Weg für eigene Anwendungen mit Unternehmens-Datenschutz.

Text bearbeiten (Rechtsklick)

Text auf einer beliebigen Webseite markieren → Rechtsklick → „KI: Text bearbeiten“. Das Ergebnis ersetzt die Markierung direkt im Eingabefeld; ist das Feld nicht beschreibbar, erscheint ein Overlay mit Kopieren-Button. Eingebaute Aktionen: Umformulieren, Formeller, Lockerer, Kürzer, Rechtschreibkorrektur, Übersetzen (DE/EN). Eigene Aktionen mit eigenem Prompt lassen sich in den Optionen ergänzen.

KI-Antwort im Ticket

Im „Email senden“-Fenster den Button „✨ KI-Antwort“ klicken: Die KI liest den sichtbaren Ticketverlauf und entwirft eine Antwort — mit automatischer Anrede aus dem An-Feld, eingefügt vor der Signatur. Der Entwurf ist zum Nachbearbeiten gedacht, nicht zum Blindversand.

KI-Chat

Über das Popup („🤖 KI-Chat“). Nutzt den konfigurierten Anbieter; unterstützt Mehrrunden-Gespräche und einfache Formatierung (fett, Code). Der Verlauf funktioniert wie gewohnt: Die Seitenleiste (☰) listet die Unterhaltungen der letzten 30 Tage mit automatischen Titeln — anklicken zum Fortsetzen, ✕ zum Löschen, „＋ Neuer Chat“ beginnt eine frische Unterhaltung. Die Kontextmenü-Suche „In InnoGPT fragen“ nutzt dieselbe Seite.

Suchen (Rechtsklick oder Popup)

Markierten Text (z. B. eine Fehlermeldung) in der DATEV Wissensplattform, bei Google oder per KI nachschlagen. Im Popup gibt es dafür das Suchfeld mit drei Buttons (Enter = DATEV).

Termin aus dem Ticket

Button „📅 Termin“ in der Ticket-Toolbar: übernimmt Kunde, Ticketnummer, Bezeichnung, Ansprechpartner, Telefon und E-Mail. Terminart wählbar (Telefon/Teams/Vor Ort — bei „Vor Ort“ wandert die Kundenadresse ins Ort-Feld). Ausgabe wahlweise als ICS-Datei (Outlook Desktop) oder direkt in Outlook Web. Auf Wunsch wird der Ticketstatus danach automatisch auf „Termin vereinbart“ gesetzt (abschaltbar in den Optionen).

Anfahrt: Bei „Vor Ort“ kann zusätzlich ein separater Termin „Anfahrt: …“ direkt vor dem Haupttermin angelegt werden (Fahrtzeit wählbar, Startpunkt „von aktuellem Ort“ oder „von der Firma“ — die Firmenadresse kommt aus den Optionen → Ticket-Termin). Bei der ICS-Variante werden zwei Dateien heruntergeladen (der Browser fragt ggf. einmalig, ob mehrere Downloads erlaubt sind); bei Outlook Web öffnet der Anfahrt-Termin nach einem zweiten Klick, da Browser nur ein Fenster pro Klick zulassen.

Route: Der Knopf „🚗 Route“ neben der Anfahrt-Zeile öffnet die Strecke in Google Maps — Startpunkt ist der daneben gewählte („aktueller Ort“ oder Firmenadresse), Ziel die Adresse aus dem Formular. Die angezeigte Fahrzeit gilt für die aktuelle Verkehrslage: Ein Google-Maps-Link kann keine geplante Abfahrtszeit übergeben, die URL-Schnittstelle kennt dafür keinen Parameter.

Mit Vorbehalt: Auf Wunsch wird der Termin als „Mit Vorbehalt“ (Frei/Gebucht-Status Tentative) angelegt. Das funktioniert nur über die ICS-Datei — der Outlook-Web-Link unterstützt diesen Status nicht, dort bitte manuell umstellen.

Weitere Ticket-Buttons

  • 📵 Nicht erreicht: legt einen Ticket-Eintrag mit konfigurierbarem Text an und speichert ihn.
  • 🔔 Abo: abonniert das Ticket (öffnet bei Bedarf kurz den Abonnenten-Tab und kehrt zurück).
  • 🚗 Anfahrt: Google-Maps-Route zur Kundenadresse — vom aktuellen Standort oder von der Firmenadresse.
  • ⚡ Makros: selbst konfigurierte Aktionsketten (siehe unten). Der Button erscheint nur, wenn Makros angelegt sind.

Aktions-Makros

In den Optionen unter „Aktions-Makros“ definierst du Ketten aus: Eintragstext anlegen und/oder Status setzen (beides wird als ein Ticket-Eintrag gespeichert), Ticket abonnieren und/oder das Ticket-Fenster danach schließen. Der Statusname muss exakt dem Text im Status-Dropdown entsprechen. Beispiel: „Nicht erreicht + Wiedervorlage“ = Eintrag „Kunde nicht erreicht ({datum} {zeit})“ + Status „Wiedervorlage“ + Fenster schließen.

Wartezeit-Ampeln

Im geöffneten Ticket oben links als Badge (Basis: ältester sichtbarer Eintrag) und in der Ticketliste als farbige Kurzangabe vor der Ticketnummer (Basis: Spalte „Erstellt am“ — die Spalte muss eingeblendet sein). Standard-Schwellen bei normaler Priorität: grün < 1 Tag, gelb < 3 Tage, rot ab 3 Tagen; bei Priorität „Hoch“: grün < 15 Min, gelb < 1 Std, rot ab 1 Std. Die Schwellen sind über die Konfigurationsdatei anpassbar.

DATEV-Fehlercode-Links

Meldungs-IDs wie DB60012, ZK01052 oder INI07257 werden in den Ticket-Einträgen automatisch erkannt und verlinkt — ein Klick öffnet die Suche in der DATEV Wissensplattform. Abschaltbar über die Feinschalter.

Popup (Klick aufs Toolbar-Icon)

  • Start-Leiste: öffnet alle als „Start“ markierten Links auf einmal (bereichsübergreifend).
  • Bereiche: frei definierbare Link-Gruppen (Optionen → Popup-Bereiche): eigener Name, beliebig viele Kacheln, Reihenfolge per ↑/↓; gestrichelte Kacheln öffnen im privaten Fenster.
  • Suche (ein Feld): erkennt die Eingabe automatisch — 6+ Ziffern öffnen das Ticket, 4–5 Ziffern den Kunden (Button wechselt Beschriftung und Farbe), Freitext sucht per Enter im Standard-Ziel (einstellbar unter Darstellung) oder über die drei Buttons.
  • Werkzeug-Buttons: KI-Chat (nur sichtbar, wenn ein API-Key hinterlegt ist), Clipper, Browserdaten, ggf. Inkognito-Reset, Optionen, Hilfe.
  • 🧹 Browserdaten: öffnet den Browser-Dialog „Browserdaten löschen“ (Firefox: Strg+Umschalt+Entf).
  • 🕶 Inkognito-Reset: nur in privaten Fenstern sichtbar — verwirft die private Sitzung (Cookies, Logins) und öffnet automatisch ein frisches privates Fenster.
  • Seitenleiste: Optional öffnet der Icon-Klick statt des Popups eine dauerhafte Seitenleiste (Optionen → Darstellung; Chrome/Edge/Brave). In Firefox über Menü → Ansicht → Sidebar.

Artikel-Clipper

Über das Popup („✂ Clipper“) oder Rechtsklick auf eine Seite → „Seite als Artikel exportieren“: Die Seite wird mit Mozilla-Readability bereinigt (keine Werbung, keine Navigation, nur der Artikel mit seinen Bildern) und in einer Vorschau geöffnet. Von dort:

  • 📋 Formatiert kopieren — mit Formatierung und Bildern in die Zwischenablage, direkt per Strg+V in OneNote, Word oder Outlook einfügbar (Ersatz für den OneNote-Clipper)
  • 📝 Markdown / 💾 HTML-Datei / 🖨 Drucken (PDF) / ✉ Per E-Mail teilen
  • ✨ Zusammenfassen und 🌐 Übersetzen (Zielsprache wählbar) über den konfigurierten KI-Anbieter — das Ergebnis lässt sich separat kopieren oder per E-Mail teilen

Videos, Audio und Social-Media-Einbettungen werden automatisch entfernt — der Clip enthält nur Text und echte Inhaltsbilder. Über 🕘 Verlauf sind die geclippten Artikel der letzten 30 Tage als Linkliste erreichbar. Die Aufbereitung läuft vollständig lokal; nur die KI-Funktionen senden den Artikeltext auf Klick an den konfigurierten Anbieter (Zustimmung im KI-Bereich erforderlich).

MS Account Cleaner

Auf der Microsoft-Kontoauswahl (login.microsoftonline.com u. a.) erscheint unten rechts „Alle Konten entfernen“: entfernt gemerkte Konten über das seiteneigene „Abmelden und vergessen“-Menü. Geschützt sind Konten „Mit Windows verbunden“ sowie alle Einträge der Whitelist (Optionen → MS Account Cleaner; exakte Adresse oder Domain-Teilstring wie @firma.de).

Sicherung & Verwaltung

  • Export: alle Einstellungen (inkl. API-Keys) als JSON-Datei — als Backup oder zur Team-Verteilung.
  • Importieren (aktualisieren): führt zusammen — nur Schlüssel aus der Datei werden ersetzt, API-Keys bleiben erhalten.
  • Importieren (überschreiben): ersetzt sämtliche Einstellungen durch den Dateiinhalt (Vorsicht: nicht enthaltene Schlüssel, z. B. API-Keys, gehen verloren).
  • Automatische Sicherung: täglich wird die Konfiguration lokal gesichert (30 Tage) — Wiederherstellung über die Auswahl im Sicherungs-Bereich.
  • Alles zurücksetzen: neutraler Auslieferungszustand inkl. Widerruf der Ticketsystem-Berechtigung.
  • Status: ganz oben in den Optionen — zeigt Version, API-Key, Ticketsystem-Berechtigung, Module und GPO-Vorgaben auf einen Blick.
Zentrale Verteilung: Installation und Vorgaben können per Gruppenrichtlinie ausgerollt werden (Managed Storage). Details im gpo/-Ordner des Repos.
